## 📁 Projects

### 🚆 YatraX
*Go · PostgreSQL 16 · Redis · Redpanda (Kafka API) · Next.js 15 · React · TypeScript · Tailwind · Expo · Docker · Prometheus · Grafana*

A railway booking and operations platform on the real Indian Railways network (**2,957 stations, 2,249 trains**): seven role-based apps (passenger, TTE, station, display board, control centre, staff portal, catering) on one Go core. The users and money are synthetic; the engineering problems are real.
- **No double bookings:** segment-range berth allocation enforced by a PostgreSQL **GiST exclusion constraint**, stress tested with **1,000,000 booking attempts from 48 workers: 0 overlaps**
- **Transactional outbox → Redpanda:** cancellations, refunds and waitlist promotions are never lost, with idempotent consumers
- **Double-entry ledger** with a trigger that rejects unbalanced transactions, plus a reconciler for lost payment callbacks
- **Fair Tatkal waiting room** over WebSockets with bot detection, tested with **5,000 simulated users**
- **Offline-first TTE app** (Expo) and **chaos drills** that recover on their own

### 🛵 RidePulse
*Django · DRF · Channels · Celery · PostgreSQL 16 · Redis · React 19 · TypeScript · Tailwind · DuckDB · dbt · Dagster*

A full ride-hailing platform, like Uber, Ola or Rapido, built end to end for **33 cities** across Tamil Nadu, Kerala, Karnataka and Andhra Pradesh: a rider app, a driver app and an operations console, kept live by a bot fleet driving in real time.
- **Dispatch** (sequential and batched, Hungarian assignment), surge pricing, upfront fares and live maps over WebSockets
- **Data platform:** PostgreSQL → privacy-filtered **Parquet lake** → **DuckDB + dbt** star schema with **68 data-quality tests**, orchestrated daily by **Dagster**
- **493 REST operations** with JWT auth and OpenAPI docs
- **Quality:** 462 tests, 20 Playwright browser tests, a Locust load test and CI on GitHub Actions
