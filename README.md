## 📁 Projects

### 🚆 YatraX — *Planned*
*Go · Next.js · TypeScript · PostgreSQL · Redis · Redpanda (Kafka) · Python ML · Docker*

A full-scale Indian railway booking platform built on synthetic data: 7 apps (passenger, Tatkal waiting room, TTE, station, catering vendor, control centre and zone dashboards) around one realistic railway network of ~300 stations and ~120 trains. The focus is **correctness under load**:
- **Segment-based seat allocation** with quotas, so one berth can serve MAS→SA and SA→ERS without overlap
- **Event-driven WL → RAC → CNF promotion engine** that is idempotent and replayable
- **Payment saga + reconciliation**, so no passenger is ever charged without a ticket
- **Fair Tatkal waiting room** with bot detection, targeting 5,000 concurrent users and zero double bookings
- **Live train simulation** feeding status, delays, platform changes and a control-room delay-ripple view
- **ML features**: PNR confirmation prediction (XGBoost) and festival demand forecasting
